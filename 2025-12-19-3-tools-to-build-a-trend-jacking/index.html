  • n8n

Total cost: $20-30/month (depending on usage)

Setup time: less than 15 minutes

Here’s Why We’re Using These Tools (And Not Others):

When it comes to AI tools, it’s impossible to keep up with everything that’s coming out, day after day, even if all you’re doing is tracking the major labs.

These tools are more flexible than most of the other platforms, and integrate with your existing softwares in almost all cases.

  1. N8N For Orchestration We use n8n for prototyping all AI workflows and ideas we have. It behaves like other workflow builders, but with stronger AI features. Think of it like a software domino set, where you can set up bricks from your email, marketing platforms, news sources, and then inject AI to make decisions at different points along the way. Plus the canvas interface is easy to use.

  2. Tavily For Industry Research Tavily is the most specific of the tools. Its job is to give AI access to the live internet. Most AI models only know what they were trained on, which means they’re blind to anything recent. Tavily solves that by letting AI search the web in real time and return clean, usable text instead of a list of links. That makes research faster, answers more accurate, and workflows far more reliable.

  3. Claude (Or ChatGP) For Writing This is your agent’s brain. You need the API, not ChatGPT Plus or Claude Pro. We prefer Claude. The output is clearer, more natural, and needs less editing, especially for longer or more nuanced writing. But if you prefer ChatGPT, you can swap it in.

Here’s What To Set Up Today:

The whole point of of this mini-course is that you’ll learn by doing.

But you need these three accounts ready so you’re not fumbling with API keys and payment details when it’s time to wire everything together.

Step 1: Create your n8n account (5 minutes)

Go to n8n.io/cloud and start the free trial or jump straight to the $24/month plan.

Both work.

Once you’re in, poke around the dashboard. You don’t need to build anything yet. Just get familiar with where things are.

Step 2: Get your Tavily API key (2 minutes)

Head to tavily.com and sign up.

Confirm your email. Go to the dashboard and copy your API key.

Stick it in a password manager like 1password, your notes app, a Google Doc, wherever you keep important stuff.

You’ll need this key to configure your research agents.

[

](https://substackcdn.com/image/fetch/$s_!SiYm!,f_auto,q_auto:good,fl_progressive:steep/https%3A%2F%2Fsubstack-post-media.s3.amazonaws.com%2Fpublic%2Fimages%2Faa3569a8-412f-404f-8223-33e7d279e17a_3050x1662.png)

Step 3: Set up your AI API access (5 minutes)

Pick Claude OR OpenAI.

You only need one for now.

  • If you go with Claude: Head to console.anthropic.com, create an account, add $20 to your balance, and generate an API key.

  • If you go with OpenAI: Go to platform.openai.com, set up your account, add $20, and grab your API key.

Save your key with your Tavily key.

Optional (if you’re feeling ambitious):

Watch this 15 minute n8n Quick Start.

This will help you get comfortable with how the canvas works, how you drag nodes onto the screen, how you connect them, and how you test each step.

This’ll make your setup smoother because you won’t be learning the interface and the logic at the same time.

Boom!

Now, you’re ready to start building.
